# ⚔ 검 강화하기

브라우저에서 바로 실행되는 검 강화 게임입니다. 설치나 로그인 없이 플레이할 수 있습니다.

- 플레이: https://harln1.github.io/sword-game/

## 규칙

| 구분 | 내용 |
|---|---|
| 플레이어 행동 | 강화하기(Space) 또는 판매하기(S) |
| 성공 조건 | 검을 **+10**까지 강화 |
| 실패 조건 | 골드가 강화 비용보다 적고 팔 검도 없을 때(+0) **파산** |
| 강화 | 비용 = 50 + 30 × 현재 단계. 단계가 오를수록 성공 확률이 내려감 |
| 실패 시 | +0~+4는 유지, +5부터는 1단계 하락 |
| 파괴 | +6부터 발생. 파괴되면 +0 나무 막대로 돌아감 |
| 판매 | 현재 검을 팔아 골드를 받고 +0부터 다시 시작 |
| 계속 도전 | +10 달성 후 +20까지 최고 기록 도전 가능 |

### 확률 공식 (난이도 값 = `decay`, 기본 8)

- 성공 확률 = max(15, 100 − 단계 × decay) %
- 파괴 확률 = +6부터 (단계 − 5) × 4 %, 최대 30 %
- 나머지는 유지(+0~+4) 또는 하락(+5~)

난이도 실험에서는 `decay` 하나만 바꾸고 나머지 값은 고정합니다. 화면 아래 **플레이 기록**에서 값을 고르면 다음 판부터 적용됩니다.

## 조작

| 키 | 동작 |
|---|---|
| Space / 강화 버튼 | 강화 1회 (키를 꾹 누르면 반복 입력마다 1회씩 연속 강화) |
| S / 판매 버튼 | 판매 (꾹 누르면 연속) |
| P, Esc | 일시정지 / 계속하기 |
| Enter | 시작 · 계속하기 · 새 게임 |
| R | 새 게임 (일시정지·종료 화면에서) |
| C | +10 달성 후 계속 도전 |

창이나 탭을 벗어나면 자동으로 일시정지됩니다.

## 저장 데이터

`localStorage`의 `sword-enhance-save` 키 하나에 저장합니다.

| 새 판마다 초기화 | 브라우저에 보존 |
|---|---|
| 현재 단계, 골드, 경과 시간, 시도·판매·파괴 횟수, 최근 결과 | 최고 강화, 클리어 횟수, 끝낸 판 수, 누적 파괴, 검 도감, 설정(소리·움직임·난이도 값), 플레이 기록 |

- 저장값이 **비어 있으면** 기본값으로 시작합니다.
- 저장값이 **손상되면**(JSON 오류, 버전 불일치) 원본을 `sword-enhance-save-corrupt-backup`에 백업하고 기본값으로 시작하며, 화면 위에 안내를 띄웁니다.
- 일부 항목만 잘못되면 그 항목만 기본값으로 고칩니다.

## 효과와 옵션

| 효과 | 실행되는 이벤트 | 소리 끄기 | 움직임 줄이기 |
|---|---|---|---|
| 검 번쩍임 + 상승음 | 강화 성공 | 소리 즉시 정지 | 번쩍임 즉시 정지, 이후 생략 |
| 화면 흔들림 + 파편 + 파괴음 | 파괴 | 소리 즉시 정지 | 흔들림·파편 즉시 정지, 이후 생략 |

운영체제에서 "동작 줄이기"를 켜 두었다면 처음 접속할 때 움직임 줄이기가 켜진 상태로 시작합니다.

## 검사 도구

화면 맨 아래 **검사 도구 (과제 확인용)**를 펼치면 다음 도구가 있습니다.

- 입력 카운터와 "1초 동안 Space 10회 보내기" (연속 입력 검사)
- 효과 실행 횟수 (이벤트 수와 효과 실행 수 비교)
- 저장값 보기 / 빈 저장값으로 새로고침 / 손상된 저장값 넣고 새로고침 / 전체 초기화

## 공개 안전성

- 외부 라이브러리, 외부 이미지, 외부 서버 요청이 없습니다. 그림은 모두 SVG 코드로 직접 그렸고 소리는 Web Audio로 만듭니다.
- 개인정보를 수집하거나 표시하지 않습니다. API 키, 비밀번호 같은 비밀값이 없습니다.
